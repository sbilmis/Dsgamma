Figure 1: Borel form-factor stability
=====================================

This directory contains the first paper figure:

- `plot_figure1.wl` - Mathematica/MaTeX plotting script.
- `figure1_borel_form_factors_mathematica.pdf` - Mathematica/MaTeX
  vector export for LaTeX.
- `figure1_borel_form_factors_mathematica.png` - Mathematica/MaTeX
  raster preview.
- `plot_figure1_preview.py` - Python/Matplotlib comparison script.
- `figure1_borel_form_factors_python.pdf` - Python comparison export.
- `figure1_borel_form_factors_python.png` - Python comparison preview.

Run the Mathematica/MaTeX export from the repository root with:

```bash
/Applications/Wolfram.app/Contents/MacOS/WolframKernel \
  -script papers/Ds_Bs_gamma/figures/figure1_borel_form_factors/plot_figure1.wl
```

The script loads MaTeX directly from the local paclet repository and configures
`pdflatex` and Ghostscript as:

```wolfram
"pdfLaTeX" -> "/Library/TeX/texbin/pdflatex"
"Ghostscript" -> "/opt/homebrew/bin/gs"
```

The script reads the existing numerical scan
`figure1_borel_form_factors.csv` and plots `|g|` as a function of `M^2`
for the four channels described in the current Figure 1 caption.  The
CSV is generated by `build_figure1_data.py`.

The plotted threshold values are:

- `D_{s1}(2460)`: `s0 = 8.5, 9.0, 9.5 GeV^2`
- `D_{s1}(2536)`: `s0 = 9.0, 9.5, 10.0 GeV^2`
- `B_{s1}(5750)`: `s0 = 39, 40, 41 GeV^2`
- `B_{s1}(5830)`: `s0 = 40, 41, 42 GeV^2`

The panel y-ranges are intentionally not tight to the data.  Each panel
uses a minimum vertical span so that small residual Borel dependence is
shown without visually exaggerating the variation.

Background grid lines are disabled in both versions for a cleaner
publication style.

The three curves use both color and line style so they remain separable
in grayscale print: solid, dashed, and dot-dashed.
