# Figure 1 s0-Stability Diagnostic

Internal diagnostic only.  This scans `g(s0)` at fixed representative `M^2`
values, complementing the main Figure 1 scan of `g(M^2)` at fixed `s0`.

Recommended use: keep for checks or referee response, not as a default paper
figure unless additional stability evidence is needed.

## Files

- `build_s0_stability_data.py` builds the CSV data.
- `plot_s0_stability.wl` creates the Mathematica/MaTeX PDF and PNG.
- `plot_s0_stability_preview.py` creates the Python comparison PDF and PNG.
