# Figure 4: Literature Comparison

This folder contains a draft log-scale comparison between the preferred
widths of this work and the Bondar--Milstein benchmark values quoted in the
paper discussion.

## Files

- `figure4_literature_comparison.csv` stores the plotted values.
- `plot_figure4.wl` creates the Mathematica/MaTeX PDF and PNG.
- `plot_figure4_preview.py` creates the Python comparison PDF and PNG.

## Recommendation

Use this figure only if it adds value beyond the numerical comparison table.
The log scale makes the suppression of the higher states visible, but it also
emphasizes model-to-model normalization differences.
